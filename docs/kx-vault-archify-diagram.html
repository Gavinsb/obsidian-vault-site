Doug KX Knowledge Vault Microsite

Archify-style architecture view of the local-first Obsidian vault microsite, its runtime services, derived indexes, protected write path, and public read surface.

Source of truth: Markdown files and attachments in the Doug KX vault. The microsite index is derived and rebuildable.
Write safety: authenticated saves require ETag preconditions and use atomic filesystem writes.
Runtime: two user systemd units keep the local app and quick tunnel alive outside any chat session.
Public surface: public reads are open; content, account, and operational mutations are protected.
